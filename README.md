# Wanderly

A personal travel bucket-list application built with Flutter.

- Specification: [`docs/project-specification.md`](docs/project-specification.md)
- Platform: Flutter 3.x / Dart 3.x (Android + iOS)
- Theme: Ocean teal + warm coral (Material 3)

## Structure

```text
lib/
  main.dart
  models/        Destination, Category
  repositories/  DestinationRepository (in-memory + optional persistence)
  screens/       Explore, Detail, Add, Saved
  widgets/       DestinationCard, FavouriteButton, RatingStars, ...
  theme/         app_theme.dart
assets/images/   local destination images
test/            unit tests
```

## Getting started

Flutter SDK and an Android/iOS toolchain are required to build and run:

```powershell
flutter pub get
flutter test
flutter run
```

The `android/` and `ios/` runner folders are generated by `flutter create .` once the
Flutter SDK is installed.
